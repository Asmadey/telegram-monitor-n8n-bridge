# Design System — Mauve Palette

Переработано из `DESIGN-kraken.md`: структура разделов сохранена, цвета, роли и правила заменены на палитру со скриншота. Пять цветов из скриншота и два добавленных: `#484C79` для текста и `#FFFFFF` для текста на тёмных блоках. Всего семь.

## 1. Визуальная тема и атмосфера

Спокойная палитра: светло-сиреневый фон, пыльно-розовый и лиловые тона, тёмный сине-фиолетовый для действий и текста. Поверхности плоские, градиентов нет, тени едва заметны. Палитра закрыта: семь цветов, новых оттенков не вводим.

**Ключевые черты:**
- От светлого к тёмному: Mauve → Rosy Taupe → Lilac Ash → Lavender Purple → Dusty Grape → текстовый ink
- Один акцент на экран: одна кнопка `#4E5283` или один тёмный блок
- Градиенты запрещены
- Один шрифт для всего, иерархия задаётся размером и весом
- Скругление кнопок 12px, не пилюля

## 2. Палитра и роли

## Colors (coolors.co/d9bbf9-cca7a2-aa9fb1-7871aa-4e5283-484c79-ffffff)

```
--color-canvas:    #D9BBF9;  # Mauve. Фон страницы, 50%
--color-surface:   #CCA7A2;  # Rosy Taupe. Полосы секций, 20%
--color-muted:     #AA9FB1;  # Lilac Ash. Разделители и рамки карточек, 10%
--color-accent:    #7871AA;  # Lavender Purple. Декор и иллюстрации. НЕ текст, 5%
--color-ink-text:  #484C79;  # НОВЫЙ. Весь текст на Mauve и ссылки, 10%
--color-ink:       #4E5283;  # Dusty Grape. Кнопки действий, тёмные блоки, рамки полей, фокус, 5%
--color-paper:     #FFFFFF;  # НОВЫЙ. Текст только на тёмных блоках (--color-ink), 0%
```

Rules:
- Один акцент на экран: одна кнопка `--color-ink` или один тёмный блок
- Градиенты запрещены
- Только семь цветов. Новые оттенки не вводим
- Белый `--color-paper` не ставим на Mauve: контраст 1.69:1
- Прозрачность палитровых цветов допускается только в тенях

## 3. Контраст (WCAG, проверено по формуле)

| Пара (текст / фон) | Коэффициент | Что проходит | Для чего использовать |
|---|---|---|---|
| `#484C79` / `#D9BBF9` (ink-text / canvas) | **4.81:1** | 4.5:1 ✓ обычный текст | Весь основной текст, ссылки, текст на карточках |
| `#FFFFFF` / `#4E5283` (paper / ink) | **7.35:1** | 4.5:1 ✓ обычный текст | Текст кнопок и бейджей, текст на тёмных блоках |
| `#FFFFFF` / `#484C79` (paper / ink-text) | 8.12:1 | 4.5:1 ✓ | Hover-состояние тёмной кнопки |
| `#484C79` / `#CCA7A2` (ink-text / surface) | 3.72:1 | 3:1 только для крупного текста | Заголовки ≥ 24px на полосах секций |
| `#4E5283` / `#D9BBF9` (ink / canvas) | 4.35:1 | 3:1 для UI и границ | Рамки полей, фокус, рамка кнопки-контура. Не текст |
| `#4E5283` / `#CCA7A2` (ink / surface) | 3.36:1 | 3:1 для UI | Рамки и фокус на полосах секций |
| `#FFFFFF` / `#D9BBF9` (paper / canvas) | 1.69:1 | ничего | Запрещено |
| `#484C79` / `#AA9FB1` (ink-text / muted) | 3.21:1 | 3:1 только для крупного | Не используем: Lilac Ash только для декора и рамок |
| `#7871AA` / `#D9BBF9` (accent / canvas) | 2.62:1 | ничего | Только декор, не текст и не иконки смысла |
| `#7871AA` / `#4E5283` (accent / ink) | 1.66:1 | ничего | Запрещено |
| `#CCA7A2` / `#D9BBF9` (surface / canvas) | 1.29:1 | ничего | Фон к фону, без текста и границ |

**Что из этого следует:**
- **Обычный текст** выводим только в парах `ink-text` на `canvas` (4.81:1) и `paper` на `ink` (7.35:1).
- **Полосы `surface`** несут только крупные заголовки. Обычный текст там не выводим (3.72:1).
- **Lavender Purple** — не текстовый цвет. Он работает только как декор рядом с текстом.

Тени только у плавающих элементов: модальных окон и выпадающих меню.

## 8. Do's and Don'ts

### Do
- Использовать `--color-ink-text` для всего текста на Mauve и для ссылок
- Использовать `--color-ink` для кнопок действий и тёмных блоков, текст на них `--color-paper`
- Делать `--color-canvas` главным фоном, `--color-surface` для полос секций
- Ставить крупные заголовки на полосы `--color-surface`
- Держать 12px на всех кнопках

### Don't
- Не использовать Lavender Purple для текста и для иконок, которые несут смысл
- Не выводить обычный текст на полосах `--color-surface`
- Не ставить белый текст на Mauve
- Не вводить восьмой цвет
- Не делать градиенты и пилюльные кнопки
- Не ставить два тёмных блока-CTA на один экран

## 11. Открытые вопросы

1. **Шрифт.** Inter — заглушка. Если у проекта уже есть шрифт, заменить в разделе 4.
2. **Доли 50 / 20 / 10 / 5 / 10 / 5 / 0.** Выбраны по смыслу ролей, не из ваших данных. `--color-paper` в долях 0%, потому что он только текст на тёмных блоках.
3. **Порядок ролей.** Назначение цветов по ролям — моё предложение. Можно поменять местами Rosy Taupe и Lilac Ash, если нужен другой характер полос.
