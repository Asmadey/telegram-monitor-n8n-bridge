# PLAN.md переехал

Живой план и таблица «Статус выполнения» версионируются вместе с кодом:

**→ [`docs/PLAN.md`](docs/PLAN.md)**

## Почему

До 2026-09-04 существовали две копии: этот файл (поддерживался, но лежал вне
git — репозиторий тогда лежал в подкаталоге `Teleton/FastAPI/`) и версионированная
копия плана, замороженная на состоянии при создании: 0 из 23 чекбоксов при 17
реально закрытых. Версионировалась устаревшая копия, поддерживалась
неверсионируемая — агент, склонировавший репозиторий, получал заведомо неверный
статус.

Это ровно то, о чём `AGENTS.md` §9: статус живёт в одном месте, остальные
документы на него ссылаются. Файл оставлен указателем, а не удалён: на него
ссылается `CLAUDE.md` и стартовые промпты прошлых сессий.

## Раскладка

С 2026-09-10 корень репозитория и корень проекта — одно место (раньше
репозиторий лежал в подкаталоге). Возврат сюда полной копии плана закрыт тестом
`tests/test_03_repo_hygiene.py::test_no_competing_plan_copy_at_the_repo_root`.
