Конфигурация

Настройки MTProto & Авторизация Telegram

1. Ключи вашего приложения (my.telegram.org)
Получите свои значения на my.telegram.org → API development tools. Они нужны, чтобы подключить именно ваш аккаунт; общих ключей сервиса нет. Оставьте поле API HASH пустым, чтобы сохранить прежний.
2. Авторизация аккаунта Telegram
✅ Аккаунт авторизован
Что происходит при подключении
  • Сервис подключается к Telegram от лица вашего аккаунта и технически получает доступ на чтение вашей переписки — так устроен MTProto, ограничить доступ только нужными каналами нельзя.
  • Ключ хранится в зашифрованном виде. Отозвать его можно из Telegram: Настройки → Устройства → завершить сеанс.
